MO 数值编辑器 v1.2.1 更新条目
（Mental Omega 3.3.6 用；覆盖旧的 exe 即可，中文名表已经打进包里）

一、新增功能
1. 免费声明 / 使用须知：第一次启动会弹一次，有「之后不再弹出」。
2. 左上角「关于」：作者、免费声明、打赏入口（微信扫码）。
3. 左上角「撤销 / 还原 / 内容」：
   - 改错了可以撤销、再还原回来（Ctrl+Z / Ctrl+Y 也行）。
   - 「内容」窗口列出当前所有改动：单位 [ID] 字段：原值 → 新值，双击可跳转，
     也可以「还原这条」「还原这个单位」。
4. 搜索框里的小 ✕：一键清空搜索。
5. 数值输入框支持直接打中文挑单位：例如在「弹头 / 支援技能 / 空投单位」这类格里
   打「心灵」「核弹」「伞兵」，会弹出候选，点一下填进去（列表型的会往后面追加）。
   顺便把中文标点自动转成英文标点（，；：（）→ , ; : ()），连续的重复标点合并成一个。
6. 数值警告：输入框左边会出现黄色 ⚠，鼠标悬停看原因。
   - 本该是数字的格子填了非数字；
   - 步兵移速超过 15（游戏里会抽搐/瞬移）。
7. 支援技能（超级武器）单独一栏：「支援技能」分类，能看到冷却、花费、效果范围、
   技能伤害、弹头，以及「由哪些建筑提供」「空投/传送什么单位」。
8. 车辆 ⇄ 建筑 的部署形态：面板底部会显示「展开成建筑 / 展开回车辆」，
   并且可以直接改建筑那边的数值（基地车部署后看的是建筑）。
9. 生成物：飞毛腿、无畏、航母这类发射器单位，底部会列出它生成的导弹/飞机。
10. 加特林逻辑：多段武器会显示成「加特林第2段（210 击破后）」这种形式。
11. 副本：除了本地另存，还能「导出改动到文件」和「从文件读取」，
    几个人的改动可以互相传（几百字节的小文件，不用传 2.2MB 的 rulesmo.ini）。
12. 窗口位置记忆、启动时自动找游戏目录（最多 5 秒）、右下角「启动游戏」。

二、数据方面的改进
1. 数值名汉化覆盖率 95.5%（64735 次字段出现里 95.5% 有中文名，没中文的显示英文原名）。
2. 中文名 579 条：官网四个阵营的单位/建筑、中立科技建筑、天蝎假货、焚风诱饵、
   渗透单位、支援技能、召唤物都在内；可搜中文名 / 英文名 / 单位 ID。
3. 分类更准：
   - 建造不出来的会灰显（科技等级不在 1~10、步兵载具没有 Owner= 之类），
     灰显排在「亮色中文名」和「纯英文名」之间；
   - 16 个渗透单位虽然没写 Owner=，但属于正常可造，不灰显；
   - 「中立&其他」整栏不灰。
4. 修复：弓箭手（HARP）之前被错挂到 ARCH 上导致搜不到；
   迪布克攻击机 → 恶灵拦截机、野牛战斗坦克 → 蛮牛战斗坦克、企业号大黄蜂 → 企业号黄蜂无人机。

三、修的问题
1. 保存后左下角还显示“未保存”（现在保存后状态就对了）。
2. 切换单位后右侧面板有时停在中间（现在每次都回到顶部）。
3. 分类按钮点下去尺寸会变（现在固定）。
4. 武器/派生段里「另有多少个单位使用同种武器」的啰嗦提示已去掉。
5. 主武器和精英主武器是同一把枪时，输入框空白（已修）。

四、用法提醒（老规矩）
- 只读 .mix，不改原包；保存时在游戏目录生成 / 更新一个松散的 rulesmo.ini。
- 「全部还原」= 删掉那个 rulesmo.ini，立刻回原版。
- 联机：双方规则文件必须完全一致，版本不同先点「重新提取」再保存。
- 首次运行会在 exe 旁边生成 MOINIEditor_data 文件夹（缓存 + 备份），别删。
- 杀软拦 exe 就用「文件夹版」。
