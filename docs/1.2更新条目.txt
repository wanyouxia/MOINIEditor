MO 数值编辑器  v1.2  更新条目
更新日期：2026-11-06
覆盖旧的 MO数值编辑器.exe 即可，数据不用重装；第一次打开会自动生成/沿用 MOINIEditor_data。

==================== 一、新增：支援技能 ====================

1. 分类栏多了「支援技能」一格，一共 135 个（攻击型超级武器、支援型超级武器、空投、维修、传送等）。
2. 每个技能的面板顶部就是它的参数，可以直接改：
   冷却、花费、施法距离、最大距离、技能伤害、技能弹头、释放动画、
   AI 使用方式、侧边栏分组、是否显示图标、可穿烟释放、被哪些建筑禁用。
3. 面板里会写「由 N 个建筑提供：xxx」，名字可以点，直接跳到那个建筑。
4. 反过来，建筑面板底部有「── 提供的支援技能」，可以直接改 SuperWeapon / SuperWeapon2，
   也可以点「换成…」从 135 个技能里挑一个换上。
   （这就是「让某个阵营凭空多一个超武」的做法：给它的建造场挂一个技能就行。）
5. 空投/传送类技能会多一段「空投 / 传送内容」，列出它会丢下来的单位：
   - 兵种列表可以直接改 ID（比如把空降坦克换成丢别的东西）；
   - 空投数量（PARADROP.COUNT）单独一行，也可以改；
   - 像中立机场那种兵种写在全局规则的，会提示去 [General] 改 AmerParaDropInf / AllyParaDropInf 等。

==================== 二、新增：部署形态 ====================

基地车 → 建造场、机械造物 → FABOID、迷雾机动车 → YAQUAD 这类「部署后变建筑」的单位，
面板底部多一段「部署形态 · 展开成建筑：盟军建造场 [GACNST]」，
下面是那个建筑的 价格 / 生命 / 装甲 / 电力 / 视野（改的是建筑那一节，因为部署后看的是建筑）。
一共 35 个，四个阵营的基地车全在里面。

==================== 三、新增：加特林（盖特）单位的全部武器段 ====================

圣骑士猎杀坦克、天启、加特林坦克这类 IsGattling=yes 的单位，武器挂在 Weapon1~6 上。
之前界面只认主/副/精英三个槽位，只能看到第一段。
现在会读出全部段位，并标出解锁条件：「加特林第2–4段（210/280 击破后）：JagdMissile」。

==================== 六、修了这些 ====================

1. 「启动游戏」按钮点了没反应 —— 已修。
   原因有两个：Syringe 的 exe 名必须带引号（不带就当参数无效直接退出）；
   少 -SPAWN 参数游戏会几秒后自己退。
   现在优先直接启动 MentalOmegaClient.exe（和你平时双击那个一样，菜单/战役/遭遇战都在）。
2. 选中新单位后，滚轮往下滑有时像没反应 —— 已修（之前 1.6 秒内会被程序拉回顶部）。
3. 保存后左下角还显示「未保存」 —— 已修。
4. 厄普西隆步兵「弓箭手」搜不到 —— 已修（官网锚点写错，真实节是 HARP）。
5. 支援技能、路径栏、标题栏里过长的名字不再被截断（标题自动换行）。
6. 带点的键（ParaDrop.Count、Missile.Damage…）有中文名后不再缀英文，标签更干净。

==================== 七、更方便的小东西 ====================

1. 游戏目录自动识别：第一次打开会自动扫描各盘的 Mental Omega，找到就记住，最多扫 5 秒。
2. 右下角按钮顺序：保存到游戏 / 全部还原 / 启动游戏。有未保存改动时点启动会先问一句。
3. 左上角「副本」：把这套改动存成一份（可命名/带时间），以后一键载入或删除。
   适合存「穷鬼版」「爆改版」各一套。
4. 左上角「神秘」：先选一个具体阵营（盟军/苏军/厄普西隆/焚风，中立不行），
   点一下给你随机改：该阵营所有步兵随机一项 ±，若有利则车辆往有害改，反之亦然。
   想要惊喜就点它，想还原就选单位点「还原此单位」或用「全部还原」。
5. 窗口大小和位置会记住，下次打开还是原样。

==================== 八、联机说明（重要） ====================

只要双方 rulesmo.ini 完全一致，就能正常联机（旧版说的 ForbiddenFiles 拦截并没有真的生效）。
所以约定是：房主改好 → 把 D:\Mental Omega\rulesmo.ini 发给其他人，放到同一路径覆盖。
注意 MO 版本必须一致；换版本后请先点「重新提取」再保存。
