# MO 数值编辑器 v1.2.1（Mental Omega / RA2 引擎）

双击 **MO数值编辑器.exe** 即可运行，单文件、不用装 Python。

- 首次运行会在 exe 旁边生成一个 `MOINIEditor_data` 文件夹，放缓存的原版规则和备份，**别删它**也行（删了会重新从 mix 里提取）。
- 如果杀毒软件拦这个 exe（没见过的新程序常被拦），就用 **文件夹版\MO数值编辑器.exe**，功能完全一样。
- 老办法也能跑：**启动.bat**（用自带的 python 跑 `app\moini.pyw`）。

## 怎么用

1. 打开软件，左上角确认「游戏目录」是 `D:\Mental Omega`（不对就点“选择目录”）。
   目录没设对时，顶部会有**红色警告**，保存按钮是灰的（点不动）。
2. 在搜索栏输入**中文名**、英文名或单位 ID 都能搜，例如 `骑士`、`tank`、`cavalier`、`MTNK`。
   列表显示的是官网中文名 + 单位注册名，例如 `骑士中型坦克  [MTNK]`。
   上面一排是**阵营**按钮：全部 / 同盟国联军 / 苏维埃联盟 / 厄普西隆军 / 焚风反抗军 / 中立&其他；
   下面一排是**分类**按钮：全部 / 建筑 / 步兵 / 车辆 / 空军 / 其他。
   两个可以叠加，也可以再叠加搜索。
   点阵营按钮时，整个界面会换成那个阵营的代表色（取自官网阵营徽章：蓝 / 红 / 紫 / 青）。
   左边列表里选一个单位，右边就会列出它的数值（中文名 + 原始英文键名）。
   滚轮只滚动光标所在的那一栏。
   还能直接搜武器（如 `120mm`），可以改伤害、射程、射速、连发数。
3. 直接改右边的数值（回车或点别处即生效），可以改多个单位。
   - 单位下面会带着它**用的武器**（主武器/副武器/精英…），武器数值可以直接改；
     两把武器指向同一个武器节时会合并成一段，改一次两边一起生效。
   - 武器标题右边有「弹头 XXX」按钮，点进去能改这个弹头的 11 项**伤害百分比**
     （对无甲/防弹衣/轻甲/中甲…各类装甲的伤害系数，100 = 全额）。
   - 像飞毛腿、无畏、阿库拉这种“发射器”，下面还有「派生 · 发射/生成」段，
     显示它打出去的东西（导弹/飞机），可以改它的血量、速度，还有导弹专用数值
     （Missile.Damage 等）。没有 Missile.Damage 的导弹，伤害由引擎按弹头算，
     这里会给出「伤害弹头（引擎指定 V3Warhead）：V3WH [打开这个弹头]」直接跳转。
   有武器的单位，右边下面还会列出它的**武器**，直接在原地就能改伤害、射速、射程、弹头、开火音效、弹速；
   一个单位有几把武器就列几段（主武器 / 副武器 / 精英主武器 / 精英副武器）。
   每段标题后面会写「另有 N 个单位使用同种武器：…」，改这把武器会同时影响那几个单位——
   想单独看它，点标题旁的「单独打开」。
4. 点 **保存到游戏**。之后**重新启动游戏**才生效。
5. 想恢复原版：点 **全部还原**，会删掉我们生成的那份 rulesmo.ini，游戏立刻回到原版数值。

## 它是怎么做到的（重要：“添加”而不是“修改”）

- 游戏原始的规则文件 `rulesmo.ini` 是打包在 `expandmo99.mix` 里的。本工具**只读**它，
  从不解包、不修改任何 `.mix`。
- 保存时做的事：
  1. 把原版 `rulesmo.ini` **原样复制**一份放到 `D:\Mental Omega\`（这就是“添加”一个文件）；
  2. 在**这份副本里**，把你改过的那几个键**就地改掉**，其他 2.29MB 内容一个字节都不动。

  > 早期版本是“在文件末尾追加 [单位ID] 覆盖块”，那是错的：引擎遇到重复的节是
  > **整节替换**，追加块里只有你改的键，`Owner`/`Prerequisite` 这些就全丢了，
  > 于是单位在游戏里造不出来。现在改成就地改写，节里的其他键都还在。
- 「全部还原」= 删掉 `D:\Mental Omega\rulesmo.ini` 这一个文件，游戏读到 mix 里的原版。

## 注意

- **只对单机有效**。联机（客户端里进 CnCNet）时，`ClientDefinitions.ini` 的
  `ForbiddenFiles` 会检查这些文件，请先在软件里点「全部还原」再联机。
- **MO 更新后**：点一下“重新提取”，重新从新的 mix 里取基准值。
- 数值改了进游戏没反应？先确认是真重启了游戏（不是退到主菜单），
  再确认改的是那张地图/模式里真的用到的单位。
- **弹头是共享的**：改 `V3WH` 会同时影响所有用这个弹头的爆炸（V2 导弹也算）。
  只想改飞毛腿的话，要先复制一个新弹头再把 `[CombatDamage] V3Warhead` 指过去。
- 中文名/阵营表来自官网中文站（`app\data\cn_names.json`、`cn_faction.json`）。
  焚风的**纳米同步形态**官网没有独立条目，是照官网步兵页补的，游戏里是独立单位，
  所以能单独搜到、单独改：皇家骑兵(KINGS)、轨道炮战士(RAIL)、迷幻猎手(DEVI)、
  同步忍者(SYNC_N)、增殖机器人(DUPL)、气压球晋升者(ZORB_N)、天神克星(BANE_N)。

`app\data\` 里还有：`rulesmo.base.ini` 是原版基准，
`backups\` 里是每次保存前的备份（如果你原来就有自定义 rulesmo.ini），
`cn_names.json` / `cn_faction.json` 是官网中文名与阵营对照表（343 条）。

## 目录

```
MO数值编辑器.exe      双击就能用（单文件，约 12MB，版本 v1.2）
文件夹版\             备用版本（exe + 依赖文件夹，杀软误杀时用这个）
使用说明.md           本文件
界面截图.png 等       界面截图
启动.bat             源码运行方式（用下面 python\ 跑 app\moini.pyw）
app\moini.pyw        源码（改版本号就改里面的 APP_VERSION）
app\data\            源码版的数据目录（原版基准 + 备份）
python\              自带的 Python 运行时
_打包工具\            重新出包用（build.py，详见里面的 README.md，不用发给别人）
```
