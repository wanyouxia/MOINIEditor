## 已改，等下次打包（先行版已经能用）

（v1.2 已把这批全部打包，见下方版本历史）

- **路径自动确认**：启动时如果没记录目录、或记录的目录失效，会自动在 C~Z 盘的
  `Mental Omega` / `Games\Mental Omega` / `Program Files\...` 以及各盘一级子目录里找
  （认出条件：有 gamemd.exe 且有 .mix 或 Resources 目录），找到就记住并提示「已自动识别游戏目录」。
  **最多花 5 秒**，超时就停下，左下角红字提示「自动查找超过 5 秒，请手动选择目录」。
- **软件内启动游戏**：右下角按钮顺序改为「保存到游戏 / 全部还原 / 启动游戏」（启动在最右）。
  优先用 `Syringe.exe gamemd.exe -CD -SPEEDCONTROL -LOG`（Ares 注入器，就是客户端平时用的启动方式），
  没有 Syringe 就直接跑 gamemd.exe。
  **如果有没保存的改动，会先问一句**：是＝先保存再启动 / 否＝不保存直接启动 / 取消＝什么都不做。
- **神秘选项**（副本右边的「神秘」按钮，只有选了「盟军 / 苏军 / 厄普西隆 / 焚风」才能点；
  「全部」和「中立&其他」都是灰的）：
  1. 给该阵营**所有步兵**随机挑一项（血量 / 移速 / 价格 / 攻击间隔），随机 +50% 或 -25%；
  2. 判断这一步对阵营**有利还是有害**：血量、移速 +50% 有利；价格、攻击间隔 +50% 有害（反之亦然）；
  3. 如果是**有利**，就给该阵营**所有车辆**抽一项、往**有害**方向改；如果步兵那次是**有害**，
     车辆就抽一项往**有利**方向改。
  攻击间隔改的是武器节的 `ROF`（同一把武器被别的单位共用时会一起变）。
  算出来的数值一律**向下取整**（135×0.75 = 101，不是 101.25）。
  改动只进待保存列表，点「保存到游戏」才生效。
- **支援技能（分类里新增「支援技能」一格，135 个）**：
  1. 每个技能面板顶部就是它的参数：冷却（分钟）、花费、施法距离、最大距离、技能伤害、
     技能弹头（可点「打开这个弹头」跳去改伤害百分比）、释放动画、AI 使用方式、
     侧边栏分组、是否显示图标、可穿烟释放、被哪些建筑禁用、辅助建筑；
  2. 下面一行显示**由哪些建筑提供**（可点击跳过去）；
  3. 反过来，建筑面板底部有「── 提供的支援技能」，可以直接改 `SuperWeapon` /
     `SuperWeapon2` / `SuperWeapons` 的值，或点「换成…」从 135 个技能里挑一个换上
     （这就是让某个阵营获得/失去某个技能的办法）。
  3. 支援技能的名字也汉化了：用官网中文页里每个技能的 **cameo 图标名**
     （`images/cameo/gbnkicon.png` ≈ 技能节的 `SidebarPCX`）做匹配，78 个技能拿到官方中文名
     （如「战术核弹攻击」「无敌」「超时空传送」「空降部队」），剩下的多是内部辅助技能或无图标条目。
  `Type` / `Action` 是引擎行为枚举，界面上能看到但建议别改。
- **窗口位置记忆**：退出时把窗口大小、位置（以及是否最大化）记到 `app\data\geometry.txt`，
